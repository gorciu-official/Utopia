# Security 

## Supported versions

This project is currently in pre-release state, so I would only help you with the latest Git version on any of the active branches. That's basically it lol.

As I don't think this kernel is used really anywhere, you can just create a GitHub issue with a `Bug` label and I will probably look into it.
