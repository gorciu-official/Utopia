# Acknowledgements

This kernel was created with the help of these resources:

**Wikis and similar resources**:

- both the [original wiki.osdev.org](https://wiki.osdev.org) and [its osdev.wiki fork](https://osdev.wiki)

**OSDev projects**:

- [EvalynOS](https://git.evalyngoemer.com/evalynOS/evalynOS) was a great reference implementation for me to check some RISC-V related things
- [Limine bootloader](https://github.com/Limine-Bootloader/Limine)'s source code was incredibly helpful when adding SMP support to RISC-V; also great as a bootloader so we use it ;)
- [Epsilon](https://github.com/archivepedia/epsilon) was helpful as a reference implementation while adding an ELF loader
- I also stole some x86_64 code regarding PS/2 or IDT from my previous "operating system", [AurorOS](https://github.com/Interpuce/AurorOS)
