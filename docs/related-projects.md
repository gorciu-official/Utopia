# Utopia's related projects

...are maintained in the [MoreUtopia](https://github.com/MoreUtopia) organization, either by me (Gorciu) or by the community.

Some notable projects include:

- [fsstrap](https://github.com/MoreUtopia/fsstrap): a tool for automating creation of Utopia initramfses
  - [fsstrap-template](https://github.com/MoreUtopia/fsstrap-template): a template repository that bundles fsstrap and Utopia kernel
- [finit](https://github.com/MoreUtopia/finit): a historically first system init for Utopia, using its native syscall ABI
